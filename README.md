# Denise Barrett — Portfolio

Product designer and leader.

I design for durability. Most fragmentation is a surface problem, not a
foundation problem — so I unify the surface, protect what's underneath,
and leave a system the next team can build on.

**Live:** https://denisexue106.github.io/Website/

## Structure

Single-file static site. Everything (markup, styles, animation) lives in
`index.html` — no build step, no dependencies.

    index.html      the whole site
    img/            resume PDF + case study screenshots

## Local preview

    python3 -m http.server 8000

Then open http://localhost:8000

Drop a PDF at `img/denise-barrett-resume.pdf` — the download button in the
